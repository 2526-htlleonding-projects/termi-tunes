# Termi Tunes

**Termi-Tunes** ist ein minimalistischer, hochperformanter Musik-Client für das Terminal. Er kombiniert die Schnelligkeit einer **CLI** (Command Line Interface) mit der Übersicht einer **TUI** (Terminal User Interface).

Entwickelt für Power-User, die ihre Musik steuern wollen, ohne die Hände von der Tastatur zu nehmen.

---

## Features

* **Smart Nicknames:** Automatische Generierung von Kurznamen für Songs.
* **Collision Handling:** Intelligente Auflösung doppelter Namen.
* **Recents-Workflow:** Neue Suchergebnisse landen automatisch in einer "Recents"-Staging-Area, von wo aus sie einfach sortiert werden können.
* **Spotify & Local:** Nahtlose Steuerung von Spotify-Streams (inkl. Device-Switching) und lokaler Musiksammlungen.
* **Custom Themes:** Volle Unterstützung für Farbschemata (z. B. Dracula, Matrix, Gruvbox) für CLI und TUI.
* **Lyrics-Support:** Integrierte Songtext-Anzeige direkt im Terminal mit dem Befehl `lyr`.

---

* **Sprache:** C# (.NET 9 / .NET 10)
* **Datenbank:** SQLite mit **Dapper** als performantes Lightweight-ORM.
